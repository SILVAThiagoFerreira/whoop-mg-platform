# Roadmap

## Milestone 1 — fundação (em andamento)

Repository, documentação, dashboard React/PWA, mock provider, SQLite schema, integração Google modular, CI Pages.

## Milestone 2 — descoberta BLE

Pairing, device info, battery, live HR e raw packet storage somente após hardware disponível.

## Milestone 3 — histórico

Offload incremental, cursor/checkpoints, gaps, validação e resumos Drive/Sheets.

## Milestone 4 — sensores

PPG, R-R, ACC, gyro, temperatura e demais sensores com testes.

## Milestone 5 — analytics

Sleep, HRV, RHR, strain/recovery/stress próprios, baselines e anomalias.

## Milestone 6/7 — MG, OpenClaw e MCP

Pesquisa MG/ECG experimental, MCP local, insights e relatórios.
